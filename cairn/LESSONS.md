# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).
- 2026-09-17 (M002): The `source-tree-tests` job installs its R packages from the `r2u.stat.illinois.edu` apt mirror. A timeout there fails the job with `Unable to locate package r-cran-httptest2`, which reads like a missing dependency, or fails the "Install System Dependencies" step with exit code 100 (corrected M023). Re-run the job before investigating.
- 2026-09-18 (M003, M013): A function can delegate to one that runs its own server check. A test that mocks `is_server_running` then passes with the call site under test deleted. Mock the delegate out, then delete the call site in a scratch copy and confirm that the test goes red. `lms_load()` and `lms_unload_all()` reach `list_models()`, and `lms_chat_batch()` reaches `lms_chat()`. An argument guard hides the same way: `lms_chat()` forwards to two wrappers that re-check what it checked, so only its `api_type = "openai"` route makes its own guards load-bearing. Probe the route that has no delegate.
- 2026-09-18 (M004): A suggested package of a dependency can sit on this machine and be absent on the runners. A green local suite is then no evidence that CI is green. `httr2::req_dry_run()` needs `httpuv` this way. Before you trust a local pass, make sure that every package a new test reaches is in DESCRIPTION. To learn what a request sends, read the `req_dry_run()` body, not a bare `jsonlite::toJSON()` of the same value. A body writer can change the value before it writes it (extended M044). Socket rules also differ by system. macOS lets a bind to 0.0.0.0 share a port that 127.0.0.1 holds, and Linux refuses it. So a test whose request must reach a program on a held loopback port runs on macOS alone (extended M066).
- 2026-09-18 (M005, corrected M025): `api_error_message()` parses through `parse_json_body()` with `simplifyVector = FALSE`. A JSON array arrives as a list and never as a longer atomic vector. A length guard on a value read out of a body is therefore unreachable from any wrapper test.
- 2026-09-18 (M005): `testthat::test_path()` resolves against the running test directory. Under `R CMD check` the package sources are not there, so a test that greps `R/` skips there. It runs only under `devtools::test()`, locally and in the `source-tree-tests` CI job (corrected M078), so it is a local guard and not a dead one (corrected M006). Under covr, `R/` is the installed package's folder, which exists and holds no `.R` file. Skip on an empty file list, not on `dir.exists()` (extended M055).
- 2026-09-18 (M006): Below status 400, `rlm_abort_api()` falls back to the body text and not to `HTTP Status <n>`. A wrapper that aborts on any non-200 status reports the raw body at a 2xx or 3xx failure. The failure table runs at 400 and 503 only, so that branch is untested.
- 2026-09-18 (M004): Mocking `httr2::req_perform` skips the request's error policy. The `req_error()` line of the code under test is then untestable. Have the mock read `req$policies$error_is_error` and raise through `httr2::resp_check_status()`.
- 2026-09-18 (M007): `@inheritSection <topic> <title>` renders a doc-only `@name` block's section into the consumer's `.Rd` under roxygen2 8.x. The tag must stay on one physical line, and the title must match the source `@section` character for character, or it silently inherits nothing. roxygen2 skips a block above `NULL` that has no `@name`, so its `@section` reaches no `.Rd`. A package-level section such as the options list goes on the `"_PACKAGE"` block (extended M057). A doc-only topic is reachable only under its `@name`. Add `@aliases` for every name a user will actually type, or `?rlmstudio_no_server` returns zero topics while the class is documented.
- 2026-09-18 (M007): `devtools::document()` writes `Config/roxygen2/version` into DESCRIPTION. Upgrading roxygen2 therefore makes the no-diff `document()` gate fail on a tree nobody edited. Commit the regenerated stamp.
- 2026-09-19 (M008): A request body read back through `jsonlite::fromJSON()` loses the integer-versus-double distinction, and `expect_equal()` ignores it anyway. To prove an `as.integer()` coercion load-bearing, feed a value the coercion changes: a string, or a number with a fraction. httr2 writes a whole double in integer range with no decimal part, so such a coercion is not visible on the wire. A match on the sent text ends the field with `[,}]`, because `"ttl":300` also matches `"ttl":3000` (extended M034).
- 2026-09-19 (M008): `lms_load()` without `force = TRUE` sends two requests, the `list_models()` pre-check first. An inline mock that overwrites one captured request hides the second. The shared recorder keeps both.
- 2026-09-20 (M009, corrected M070, corrected 2026-10-17): `data-raw/knit-vignettes.R` knits the vignettes ahead of time, as DESIGN.md Conventions describe. Knitting `headless-config` starts the daemon and does not stop it (corrected M072). `knitr::knit()` keeps going after a chunk error by default, and `rmarkdown::render()` stops, so the script sets `error = FALSE`. With `collapse = TRUE`, `knit()` writes a chunk's code and its `#>` lines in one block. Output that holds backticks goes to a separate four-backtick block (corrected M070 review). By default, `knit()` runs the chunks in `parent.frame()`. A knit inside a function then lets a chunk overwrite that function's variables, so pass `envir = new.env(parent = globalenv())` (extended M070 review). A vignette sentence about what LM Studio does needs a live call that shows it after the step. Package help and a probe before the step do not show it. M071 failed review on two such sentences. The server answered at once, against "the server does not answer at once". A chat loaded an unloaded model, against "a model must be loaded" (extended M071 review). With no argument, the script knits every `vignettes/*.Rmd.orig` and rewrites the live output of each. To re-knit one vignette, pass its source: `Rscript data-raw/knit-vignettes.R vignettes/<name>.Rmd.orig` (extended M074 review). To wrap a knitr output hook such as `warning`, call `knitr::render_markdown()` first. `knit()` sets the markdown hooks only while all hooks are at their defaults (extended M076).
- 2026-09-20 (M009): `httr2::req_auth_bearer_token()` hides the token from `print(req)`, but printing an rlang condition also prints a backtrace that echoes the caller's own source line. A token written as a literal argument shows up there, and the package cannot suppress it. Assert secret-hiding on `conditionMessage()`, which is what the package composes.
- 2026-09-20 (M011): the `R-CMD-check.yaml` matrix runs on the `pull_request` trigger, and its `push` trigger is filtered to the default branch. A fix to a non-Ubuntu job runs before the pull request exists only by a manual start, `gh workflow run R-CMD-check.yaml --ref <branch>` (corrected M078). A manual run uses the workflow file of its branch, so it also checks a changed step condition before the merge (extended M080). Without one, plan that evidence for the review gate, not for implement. The slowest job, `ubuntu-latest (oldrel-1)`, took 13m18s on PR #76 and outlasted the CI wait at the merge gate, so expect the merge to need one resume (extended M076).
- 2026-09-20 (M010): the `timeout` argument of `socketConnection()` does not bound the TCP connect. Against 10.255.255.1, a routable address that drops the attempt, `is_server_running(timeout = 0.5)` returned FALSE after 60.01 seconds. The operating system decides that case. Never claim a connect deadline from that argument.
- 2026-09-20 (M010): httr2 and curl set no default request timeout, so deleting a `req_timeout()` line makes the call hang on a silent listener instead of failing. A test that bounds elapsed time therefore cannot prove the timeout line load-bearing. It catches a timeout set to the wrong value and nothing more.
- 2026-09-20 (M012): `as.list()` on a named character vector carries the names over, and jsonlite writes a named list as a JSON object rather than an array. `unname()` is what keeps the array. `is.list()` on a parsed body cannot tell an array from an object, so read the names off the serialized request bytes to probe it.
- 2026-09-20 (M012, M018): cli interpolates the braces of the string handed to it, never the braces of a value spliced into that string. A detail built in one frame and passed to an abort helper reaches the user with its braces intact, unless `cli::format_inline(.envir = parent.frame())` runs in the frame that built it. The other side of the rule: text from a server placed in the string itself, as in `cli::cli_text(x$status, ...)`, runs `{...}` as R code. Splice it in as a value (extended M027). cli shortens a vector inserted with `{x}` past 20 items to "18, …, 24, and 25". A message that must name every item joins them first with `cli::ansi_collapse(x, trunc = Inf)`. `cli::ansi_strip()` removes CSI codes and OSC 8 links only. ESC 7, ESC 8, ESC ( B, and an OSC 0 window title pass through. Text from another program needs a second pass (extended M054).
- 2026-09-20 (M013): `trimws()` strips `[ \t\r\n]` and nothing else, so `nzchar(trimws(x))` reports a form feed or a vertical tab as content. A rule worded over whitespace needs `grepl("[^[:space:]]", x)`. `[[:space:]]` in turn excludes a non-breaking space, which R treats as an ordinary character. CLI output can hold bytes that are not valid UTF-8. `gsub()` then fails with "input string 1 is invalid". Run `iconv(x, "UTF-8", "UTF-8", sub = "byte")` first, which writes such a byte as `<ff>` (extended M053). cli prints a run of spaces inside a bullet as one space, so a test of the message cannot see how the code folded spaces inside a text. Test the whitespace rule on a field that holds only whitespace (extended M054).
- 2026-09-20 (M014): `tryCatch(expr, error = )` lets a warning from `expr` through. `lms_server_status(json = TRUE)` warns before it falls back to raw lines, so a caller that reads it and warns on its own needs `suppressWarnings()` inside the `tryCatch`, or the user gets two warnings for one fault.
- 2026-09-20 (M014): polling code tests without sleeping when `local_mocked_bindings(Sys.time = , Sys.sleep = , .package = "base")` swaps in one fake clock that only a sleep moves forward. The budget arithmetic is then exact, not timing dependent. Under `devtools::check()`, a base mock did not reach `interactive()` in the byte-compiled package, and 10 consent expectations failed. A package binding `interactive <- NULL` in `R/setup.R` gives the tests a target to mock, and a call skips that non-function binding (extended M072).
- 2026-09-21 (M017): `on.exit()` at the top level of a script run by `Rscript` never runs. A `data-raw/` script that loads a model or holds a temp resource must clean up in the `finally` clause of a `tryCatch()`.
- 2026-09-21 (M017): a function that reads its `...` by exact name before it forwards them misses a shortened name that the callee matches. R matches a shortened name to a callee argument that comes before the callee's `...`. `match.call(callee, call)` over the same arguments reads them as the callee will. The same rule means that a helper option placed before `...` catches a shortened field name meant for `...`. Place such an option after `...`. `match.call()` keeps both of two same-named dots, but indexing its result by name returns the first alone, so a check over every copy reads the raw `list(...)`. Removing the dot that fills a callee argument frees that argument, and a shortened or unnamed dot then moves into it. Set that dot's value in place instead, found by `match.call()` over a call whose dots hold their positions. A test that means to pass an unnamed dot fills every formal before the caller's `...` first (extended M025, M037, M059).
- 2026-09-22 (M018): `$` on a list parsed from JSON matches a unique name prefix, so `x$choices` reads a `choicesX` field when `choices` is absent. Read server fields with `x[["choices"]]`, which matches exact names only. `attr(x, "response_id")` also matches a unique prefix, so pass `exact = TRUE` (M077).
- 2026-09-22 (M019, M015): `expect_error()` adds a backtrace to the condition it returns, so `expect_identical()` against the raised object fails. To assert that a condition passes through unchanged, catch it with `tryCatch(expr, error = identity)`. `expect_length()` takes no `info`, so a check inside a loop uses `expect_identical(length(x), n, info = )`. `expect_s3_class()` takes no `info` either. `expect_no_error()` takes no `info` either, and its `message` argument filters which errors count rather than labelling them. An `expect_error()` whose pattern does not match raises the error again, so `as.data.frame()` of a test run counts it in the `error` column, not `failed`. A planted-defect check sums both columns. Under testthat 3.3.2, that table drops a result that a block records before or between its nested `test_that()` calls, a failure included, and `test_check()` then does not stop on it. So a parent check, or a helper that calls `fail()`, goes after the last subtest or into its own subtest, and a plant on nested tests is read through a reporter that records each result. A passing parent check after the last subtest still shows `nb` 0 in that table, and a failing one shows in `failed`. `expect_warning()` catches one warning and lets a second go by. A test that asserts one warning collects them with `withCallingHandlers()` and counts them (extended M024, M037, M043, M047, M065, M067). testthat's `fail()` raises a condition of class `error`, so `expect_error()` accepts a `fail()` from inside the call it wraps. A stub that must fail the test on any call counts its calls, and the test asserts the count after `expect_error()` returns.
- 2026-09-22 (M026): every message about an entry of an array names that array. A message test that expects only the array name then cannot tell apart the faults inside it. Also expect the text of the fault, such as "is not a JSON object", and plant a wrong message to see the test go red.
- 2026-09-28 (M049): `unclass(x)[[1]]` turns a named, S3-classed, or S4 string into a plain string. `unclass()` alone keeps the S4 bit, and `as.character()` runs an S3 method of the class. To clear the bit, call `asS4(x, FALSE, complete = FALSE)`. The default `complete = TRUE` sets the `.S3Class` of an S4 class back as the class, when that S4 class contains a `setOldClass()` class. Compare a name that the user gives with a server string only after that step. jsonlite drops names and the S4 bit itself, so only a class probe or a return value shows that a sending site strips them (extended M060, M079).
- 2026-09-28 (M049): `tryCatch()` runs each handler inside the handlers listed after it. A subclass handler listed before its parent handler therefore cannot re-raise to the parent handler. Test for the subclass inside the parent handler.
- 2026-09-29 (M058): a test that strips an attribute before `identical()`, such as `without_response_id()`, cannot see that attribute differ between code paths. The batch abort kept `response_id` in two formats and dropped it in the data-frame format, and the stripped tests passed. Where paths must return the same value, compare the whole value in each path.
- 2026-10-18 (M082): the GitHub Actions docs do not say whether a job that its `if:` skips still takes its job-level concurrency group. A group on a job that runs after a build also lets an older build deploy last. So `pkgdown.yaml` sets one workflow-level group, `pkgdown-deploy` under the deploy condition and the run id otherwise, and the condition is written there and in the `deploy` job's `if:`. `actions/upload-artifact` v4.4 and later leaves out hidden files such as `.nojekyll` unless `include-hidden-files: true` is set.
- 2026-10-18 (PR #85 hotfix): the text of a curl error depends on the libcurl build. For a URL with a space, `httr2::req_dry_run()` gives "Malformed input to a URL function" on macOS and "Out of memory" (class `curl_error_out_of_memory`) with the libcurl 8.5.0 of Ubuntu 24.04, so a test that expects one text fails on the Ubuntu runners alone. Compare with curl's own error for the same call. To reproduce a Linux-only failure, run the test file in `rocker/r-ver:4.6` with `libcurl4-openssl-dev`. Colima must be started first, and only `$HOME` is mounted, so pass files on stdin with `tar`.
- 2026-10-18 (M083): a live probe that starts the server on another port changes LM Studio's last-used port, so end such a probe with a start on 1234 and a stop. A probe that downloads a model leaves it on disk, and the next knit shows it in the `list_models()` output of `getting-started`. For a download probe, take a small model from https://lmstudio.ai/models: the end of its page address is the key that `lms_download()` takes, and the name in the page's `lms get` line can fail with "not found".
- 2026-10-18 (M084): to check the help examples, run `tools::Rd2ex(f, out, commentDontrun = FALSE)` on each `man/*.Rd` and read `out`. The default `commentDontrun = TRUE` puts `## ` before each `\dontrun{}` line, so a grep for a call at line start then matches nothing and passes. A grep over the whole `.Rd` also matches the `\usage{}` line, and a brace range misreads `\examples{}`, because `\seealso{}` can follow it and `\dontrun{}` closes with a `}` at column 0.
- 2026-10-18 (M086): a test that asserts message or alert text must pin `withr::local_options(rlmstudio.quiet = FALSE)`. An unpinned one passes in a clean session and fails for a contributor whose `.Rprofile` sets the option, and it starts to fail the day its call site goes through a quiet-aware helper.
- 2026-10-18 (M087): test block times change with machine load. A CRAN-mode run right after `devtools::check()` took 97.3 s against 64.0 s on an idle machine, and it put 16 blocks over 1 s against 9. Time on an idle machine, and tie a per-block bar to one named run. In a `ListReporter` run, the `real` values of the rows sum to the wall time, so nested subtest rows are not counted twice.
