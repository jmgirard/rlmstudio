# Lessons

Durable repo lessons — build quirks, testing tricks, gotchas worth
remembering next time — captured at milestone end and surfaced at plan time.
Not status, not decisions: a lesson is a reusable "how this repo actually
behaves" note. Cross-cutting *choices* still go to `DECISIONS.md`.

One line per lesson: `- YYYY-MM-DD (M<NNN>): <lesson>`. Two caps: 50 lines
and 20,000 bytes; over either, retire or prune before adding. Corrected in
place when proven false (never append a correction).
- 2026-09-17 (M001): `httr2::url_parse()` keeps the brackets of an IPv6 literal in `$hostname` and errors on a schemeless `host:port`; normalize before handing a hostname to `socketConnection()`.
- 2026-09-17 (M001): `testthat::local_mocked_bindings(..., .package = "base")` works for `file.exists` and `socketConnection` called from package code; a listening `serverSocket()` on a random 20000–40000 port gives a real TCP target without a server.
- 2026-09-17 (M002): The `test-headless` job installs its R packages from the `r2u.stat.illinois.edu` apt mirror. A timeout there fails the job with `Unable to locate package r-cran-httptest2`, which reads like a missing dependency. Re-run the job before investigating.
- 2026-09-18 (M003): A function can delegate to one that runs its own server check. A test that mocks `is_server_running` then passes with the call site under test deleted. Mock the delegate out, then delete the call site in a scratch copy and confirm that the test goes red. `lms_load()` and `lms_unload_all()` reach `list_models()`, and `lms_chat_batch()` reaches `lms_chat()`.
- 2026-09-17 (M002): Every check workflow limits its `push` trigger to `main` and `master`, so pushing a milestone branch starts no `R-CMD-check` run. The `pull_request` trigger carries no branch filter, so the first multi-platform signal arrives with the pull request.
- 2026-09-18 (M004): A suggested package of a dependency can sit on this machine and be absent on the runners. A green local suite is then no evidence that CI is green. `httr2::req_dry_run()` needs `httpuv` this way. Before you trust a local pass, make sure that every package a new test reaches is in DESCRIPTION.
- 2026-09-18 (M005): `httr2::resp_body_json()` parses with `simplifyVector = FALSE`. A JSON array arrives as a list and never as a longer atomic vector. A length guard on a value read out of a body is therefore unreachable from any wrapper test.
- 2026-09-18 (M005): `testthat::test_path()` resolves against the running test directory. Under `R CMD check` the package sources are not there, so a test that greps `R/` skips on CI and runs only under `devtools::test()`. It still gates the local run that the implement and review gates require. It is a local guard and not a dead one (corrected M006).
- 2026-09-18 (M006): Below status 400, `rlm_abort_api()` falls back to the body text and not to `HTTP Status <n>`. A wrapper that aborts on any non-200 status reports the raw body at a 2xx or 3xx failure. The failure table runs at 400 and 503 only, so that branch is untested.
- 2026-09-18 (M004): Mocking `httr2::req_perform` skips the request's error policy. The `req_error()` line of the code under test is then untestable. Have the mock read `req$policies$error_is_error` and raise through `httr2::resp_check_status()`.
- 2026-09-18 (M007): `@inheritSection <topic> <title>` renders a doc-only `@name` block's section into the consumer's `.Rd` under roxygen2 8.x. The tag must stay on one physical line, and the title must match the source `@section` character for character, or it silently inherits nothing.
- 2026-09-18 (M007): A doc-only topic is reachable only under its `@name`. Add `@aliases` for every name a user will actually type, or `?rlmstudio_no_server` returns zero topics while the class is documented.
- 2026-09-18 (M007): `devtools::document()` writes `Config/roxygen2/version` into DESCRIPTION. Upgrading roxygen2 therefore makes the no-diff `document()` gate fail on a tree nobody edited. Commit the regenerated stamp.
- 2026-09-19 (M008): A request body read back through `jsonlite::fromJSON()` loses the integer-versus-double distinction, and `expect_equal()` ignores it anyway. To prove an `as.integer()` coercion load-bearing, feed a value the coercion changes: a string, or a number with a fraction.
- 2026-09-19 (M008): `httr2::resp_body_json()` throws on a `text/plain` body and on an unparseable `application/json` body alike, so both reach the same raw-text fallback in `api_error_message()`. A test per cause buys no package coverage the other lacks.
- 2026-09-19 (M008): `lms_load()` without `force = TRUE` sends two requests, the `list_models()` pre-check first. An inline mock that overwrites one captured request hides the second. The shared recorder keeps both.
- 2026-09-20 (M009, corrected M011): CRAN serves its macOS R 4.6 binaries as zstd archives under the `.tgz` name. The pak that `setup-r-dependencies` installs cannot extract them, so the job dies with "unknown archive type". pkgcache also attaches `mac.cran.dev` as a second download URL for those files and keeps whichever download finishes first. Route macOS through Posit Package Manager, which still serves gzip builds, and block that host.
- 2026-09-20 (M009): both vignettes start the server and make live API calls while they build. `devtools::check()` therefore reads whatever state the local LM Studio is in. On a server that requires a token, the check fails unless `RLMSTUDIO_API_TOKEN` is set in the calling environment.
- 2026-09-20 (M009): `httr2::req_auth_bearer_token()` hides the token from `print(req)`, but printing an rlang condition also prints a backtrace that echoes the caller's own source line. A token written as a literal argument shows up there, and the package cannot suppress it. Assert secret-hiding on `conditionMessage()`, which is what the package composes.
- 2026-09-20 (M011): pkgcache gates both the `mac.cran.dev` racing download and the CRAN source-Archive fallback on a repo it types `cran`. Setting `PKG_CRAN_MIRROR` to the exact URL `setup-r` gave RSPM makes `cmc__get_repos()` drop the duplicate CRAN row, so neither fires. Keep the hosts block anyway, because it is what catches the case where the two URLs differ.
- 2026-09-20 (M011): the `R-CMD-check.yaml` matrix runs on the `pull_request` trigger, and its `push` trigger is filtered to the default branch. A fix to a non-Ubuntu job therefore cannot be verified before the pull request exists. Plan that evidence for the review gate, not for implement.
- 2026-09-20 (M010): the `timeout` argument of `socketConnection()` does not bound the TCP connect. Against 10.255.255.1, a routable address that drops the attempt, `is_server_running(timeout = 0.5)` returned FALSE after 60.01 seconds. The operating system decides that case. Never claim a connect deadline from that argument.
- 2026-09-20 (M010): httr2 and curl set no default request timeout, so deleting a `req_timeout()` line makes the call hang on a silent listener instead of failing. A test that bounds elapsed time therefore cannot prove the timeout line load-bearing. It catches a timeout set to the wrong value and nothing more.
- 2026-09-20 (M012): `httr2::resp_body_json()` raises on two different causes: a body the lexer cannot parse, and a body under a content type httr2 declines to read. A `tryCatch` around it that names one cause states a falsehood for the other. `check_type = FALSE` parses by content and leaves the parse failure as the only cause the branch can have.
- 2026-09-20 (M012): `as.list()` on a named character vector carries the names over, and jsonlite writes a named list as a JSON object rather than an array. `unname()` is what keeps the array. `is.list()` on a parsed body cannot tell an array from an object, so read the names off the serialized request bytes to probe it.
- 2026-09-20 (M012): cli interpolates the braces of the string handed to it, never the braces of a value spliced into that string. A detail built in one frame and passed to an abort helper reaches the user with its braces intact, unless `cli::format_inline(.envir = parent.frame())` runs in the frame that built it.
